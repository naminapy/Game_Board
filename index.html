    メンバー

    6つのタブ

    • ボード：タスクを4つの列で管理する。◀ ▶ で移動、PCはドラッグでもOK
    • スケジュール：ガント（期間のバー）と、メンバーの予定カレンダーを切り替える
    • 進み具合：完了率や工程ごとのグラフ。PNG / PDFで保存できる
    • 日記：制作日誌。月ごとにまとまって、カードを押すと全文が開く
    • 制作管理：作業の流れ（GitHub Desktop のやることリスト）、素材リスト、プレイテストの記録、バージョンごとの変更点
    • 設定：プロジェクト、目標、カテゴリ、同期、バックアップなど

    タスクの操作

    • カードを押すと編集。キーボードは Tab で選んで Enter、Alt + ← / → で列を移動
    • 間違えたら、上の「元に戻す」か Ctrl + Z（タスク・日記・予定を最大20回まで）
    • 検索バーで、名前・メモ・カテゴリ・工程・優先度・期限から絞り込める
    • タスクに仕様書のリンク（https://）を付けると、カードに「📄 仕様書」が出る
    • サブタスクで小さなチェックリストを作れる。カードに「☑ 2/5」と出る
    • 「先に終わらせたいタスク」を選ぶと、それが終わるまでカードに「🔒 待ち」が出る（動かせなくはならない）
    • タスク一覧の上の入力欄に、タイトルだけ書いて Enter で、すばやく追加できる
    • プレイテストの「直すこと」は、ボタンひとつでタスクにできる
    • 作業の流れ：フェッチ → 開始の報告 → コミット → プルリク → 終了の報告を、チェックしながら進める。報告文はボタンでコピーできる（制作ボードがGitHubを自動で操作するわけではなく、GitHub Desktop での作業の忘れ物を防ぐための表）

    期限と通知

    • 期限が3日以内（期限切れも含む）の未完了タスクが、ボードの上に出る
    • 設定の「デスクトップ通知」を許可すると、開いたときに通知される
    • 最終目標を設定すると、「あと○日」のカウントダウンが出る

    スケジュールと予定

    • ガントのバーは、PCではドラッグで期間を動かせる。「今日へ戻る」で今日の位置に戻る
    • カレンダーの予定は、チームでは「内容を見せる項目」以外が「予定あり」だけになる（画面での表示だけの制限）

    データを守る

    • データはこの端末のブラウザに保存される。クラウド同期（GitHub）を設定すると、スマホとPCで同じ内容になる
    • ときどき「ファイルで保存」でバックアップを取る。削除したタスクは30日間ゴミ箱に残る
    • データが大きくなると警告が出る。同期の目安は約1MBまで
    • 同じタスクを別の端末で同時に変えたときは、新しい方を残して、ボードの上でお知らせする

    困ったとき

    • 画面が古いままのとき：Ctrl + Shift + R（強制再読み込み）。上に「更新する」が出たら、それを押す
    • 同期できないとき：上の「☁」のバッジを押すと、設定のデータタブが開く。エラーの文を確認する
